# NOCTARA — UI/UX Direction

## 1. Design objective

The interface should feel like a living futuristic computer system — cinematic, spatial, intelligent, and personal.

Reference feeling:

- Iron Man command interface
- private AI chamber
- holographic laboratory
- sci-fi operating system

Avoid copying any specific copyrighted UI one-for-one. Use the feeling, not a replica.

## 2. Core scene

The main scene contains:

- central NOCTARA core
- ARIA presence
- NOX presence
- Owner interaction focus
- contextual holographic surfaces
- ambient telemetry

## 3. System states

### Idle
Subtle motion. Agents visibly present but quiet.

### Listening
Microphone visualizes speech and agent attention.

### Thinking
Agent presence animates and system surfaces reveal reasoning/activity signals without exposing private chain-of-thought.

### Speaking
Agent's voice presence becomes dominant.

### Tool use
A compact floating tool panel shows the current external action.

### Autonomous run
The environment shifts into execution mode with a visible plan/progress state.

### Alert
High-risk or failed action gets strong but restrained visual focus.

### Offline
A clear degraded state with available fallbacks.

## 4. Navigation

Prefer spatial transitions and contextual panels over a permanent sidebar.

Advanced controls can appear as:

- radial menus
- floating panels
- terminal-like overlays
- holographic cards

## 5. Agent bodies

Initial bodies can be abstract rather than humanoid.

ARIA: luminous, elegant intelligence form.

NOX: darker mechanical / angular intelligence form.

Bodies should communicate state and personality without becoming a distracting game character.

## 6. Typography

Use a strong modern sans for major interface text with a monospaced accent for telemetry, logs, IDs, tool activity, and system status.

## 7. Motion

Motion should be purposeful:

- attention
- state change
- spatial focus
- transitions
- tool execution

Avoid constant noisy animation.

## 8. UX priority

1. conversation clarity
2. voice responsiveness
3. agent presence
4. task visibility
5. tool visibility
6. cinematic polish
