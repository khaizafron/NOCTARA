# NOCTARA — Project Documentation

NOCTARA is a private, single-owner AI world designed for one user (the Owner). It contains two autonomous AI entities — ARIA and NOX — with persistent memory, voice, tools, multimodal capabilities, and controlled self-improvement.

## Documentation map

- `PRD.md` — product requirements and user experience
- `ARCHITECTURE.md` — technical architecture and runtime design
- `AGENTS.md` — ARIA and NOX identity, responsibilities, behavior, and interaction model
- `MEMORY.md` — long-term memory architecture, schema, retrieval, consolidation, and correction
- `AUTONOMY.md` — Level-4 autonomy, planning/execution loop, permissions, and self-improvement
- `TOOLS.md` — tool registry, provider abstraction, API integrations, permissions, and secrets
- `SECURITY.md` — threat model, trust boundaries, sandboxing, and hard safety rules
- `UI_UX.md` — Iron-Man-inspired spatial interface direction and interaction states
- `ROADMAP.md` — implementation phases, milestones, and acceptance gates
- `.env.example` — environment variable contract for local development

## Core principle

NOCTARA is not a corporate SaaS dashboard. It is a private digital world where two AI entities live, communicate, remember, reason, operate tools, and improve their own implementation within explicit Owner authority.
