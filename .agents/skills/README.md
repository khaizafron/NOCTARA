# 🧰 NOCTARA Agent Skills Hub

Direktori ini (`.agents/skills/`) menempatkan **34 Modular Agent Skills** bertaraf industri untuk kegunaan AI Agent (Google Antigravity, Claude Code, Cursor, Codex).

Kesemua kemahiran telah disusun mengikut piawaian **First-Class Agent Skills** (setiap folder mengandungi fail `SKILL.md` dengan metadata frontmatter di aras pertama). Ini membolehkan sistem **Antigravity memuatkan (*auto-discover*) kesemua 34 kemahiran secara automatik** melalui *progressive disclosure* tanpa membazir kuota token.
